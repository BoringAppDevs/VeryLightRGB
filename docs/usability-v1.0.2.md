# Very Light RGB 1.0.2 — меню та reload

2026-11-01. Власне рев’ю змін і перевірки перед встановленням.

- **HEX:** однакове кольорове оформлення в основному екрані, палітрі та ручному вводі. #000000 та інші темні коди мають світлу підкладку. Фарбуються саме HEX-коди; після них відновлюється фон вибраного рядка. Невалідні / незавершені HEX не фарбуються як готовий колір. Ширина рахується до вставки ANSI.
- **Яскравість:** бар із 20 сегментів, відсоток і список 0–100% з кроком 5%. Стрілки переходять до сусіднього 5% пресета, включно з довільним раніше збереженим відсотком; 0 та 100 обмежуються. Відкриття й Esc не застосовують новий пресет. Веселка зберігає режим без параметрів.
- **Esc:** історія екранів зберігає scope та вибраний рядок; System → Esc повертає до попередньої зони. Зі стартової підсвітки Esc відкриває головне меню й лишає його відкритим. Ручний HEX → Esc повертає до палітри, ще один Esc — до підсвітки. Згортання — Q або явний пункт головного меню. Агент продовжує працювати.
- **Reload:** в IPC є окремий тимчасовий стан із generation ID, етапом, завершеними кроками, кількістю виходів і попередженнями. Відображаються перевірка MSI, GPU, SDK connect / контролери, збереження та застосування. Завершення й помилки видимі автоматично. Дублі R під час активного запиту не додають повторних сканів. Застарілий callback попередньої generation не перекриває новий стан при зміні backend. Зміна backend / порту під час скану не публікує старий каталог як новий.

Базовий набір: **1290 assertions**, без доступу до RGB hardware. Додані перевірки кольорів / контрасту / відновлення ANSI, меж і 5% кроків, історії навігації, root меню, тексту прогресу / помилок. SDK-емулятор із затримкою відповіді підтвердив проміжний running-етап, завершення, dedup повторних reload, збереження конфігурації та error замість помилкового успіху при пошкодженій відповіді.

На встановленій 1.0.2 реальний native reload пройшов **queued → running (3/4, застосування) → done (4/4)**, каталог має 4 доступні виходи; набір керованих виходів і всі індивідуальні стилі не змінилися. Це 3 доступні ARGB-хедери + GPU, не чотири підключені RGB-пристрої.

Вбудований console smoke test прочитав справжній буфер меню: кольоровий #C65CFF мав console attribute 13 (magenta), відобразилися бар 15%, результат reload та підказки Esc / Q. Процес меню після перевірки завершився; фоновий агент залишився. Дані читалися у контексті самого агента через `diagnostics`.

Перед установленням збережено snapshot живої конфігурації; після оновлення конфігурація збіглася повністю. У спокійному фоні агент лишився приблизно 15 МіБ working set. Повний хвилинний performance benchmark для цієї зміни меню не повторювався: UI окреме, апаратні пакети та renderer не змінені, новий progress оновлюється лише під час явної роботи, збережені 432 еталонні кадри ефектів.

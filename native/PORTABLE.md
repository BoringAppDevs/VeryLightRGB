# Very Light RGB 1.2.0

Мова інтерфейсу за замовчуванням — **English**. У головному меню **Language / Мова** можна вибрати **English** або **Українська**; вибір зберігається між запусками. Написи меню, палітри, підказки, прогрес reload і tray-меню оновлюються без перезапуску анімації.

Windows 10/11 x64. Розпакуй архів у постійну папку та запусти `VeryLightRGB.exe`. Меню саме запускає фоновий tray-агент. .NET не потрібен.

Папку `native-drivers` потрібно залишити поряд з EXE. Native · Auto / Offline знаходить сумісні USB/HID-контролери та GPU без SDK-сервера; зони доступні в звичайних меню D/L. Ядро не потребує Qt/Node/.NET, transport DLL зібрані з вихідного коду без окремого Visual C++ runtime. Коли додаткові зони не вибрані, його worker не працює у фоні.

Двічі клацни tray — відкриється головне меню; `Esc` повертає до попереднього екрана / головного меню, `Q` згортає в tray. Через tray → «Вийти» завершується агент. Дані зберігаються у `%LOCALAPPDATA%\VeryLightRGB`.

- `L` — колір / HEX, яскравість, дев’ять ефектів, кількість LED, спільний або незалежний стиль.
- `D` — вибір керованих виходів (`Space`), пробне підсвічування (`I`), лише вибраний MSI-хедер (`1`).
- `S` — автозапуск, backend, FPS, SDK-порт, Reload devices, перепідключення.
- Стрілки — вибір / зміна; `Enter` — розділ / список / ввід. `R` — перезавантаження каталогу у Devices / Пристрої та System / Система з показом прогресу.

Банер широкий, жирний і має кольоровий фон. Акцент повторює основний колір першого вибраного виходу; для вузьких вікон є компактний банер. На головному екрані немає службових хоткеїв reload / налаштувань.

HEX-коди кольорові та мають великий зразок кольору поруч. Палітра містить 32 іменовані кольори, зокрема пастельні, теплий / холодний білий та чорний; PgUp / PgDn і Home / End допомагають переглядати список. Яскравість має бар та пресети по 5%. Reload показує живі етапи й результат. `Esc` у ручному вводі HEX повертає до палітри; з палітри — до підсвітки. Налаштування не змінюються при скасуванні.

«Усе разом» застосовує змінений параметр до всіх вибраних виходів, навіть із власними стилями. Окрема зміна виходу впливає тільки на нього й автоматично створює власний стиль. Якщо параметри зон відрізняються, це позначено словом «Різні».

MSI MAG B850M MORTAR WIFI (MS-7E61) та Gainward RTX 5080 Phoenix зберігають перевірені прямі модулі. Інші контролери обслуговує включене native-ядро (2144 реєстрації детекторів); конкретна сумісність залежить від моделі/прошивки. Перевірено підключення Razer Basilisk V3 Pro Wireless із трьома зонами. VIA не гарантує потрібного RGB-протоколу. OpenRGB SDK лишається необов'язковим альтернативним backend і потребує сервера тільки коли його явно вибрано.

Звичайний ARGB не повідомляє зайнятість кабелю / фізичну довжину. Вибери фактичний хедер вручну; 1–120 LED регулюються у меню. Кілька вентиляторів на паралельному splitter повторюють один сигнал. GPU — одна зона. Профілів немає; зміни зберігаються автоматично.

Закрий інші програми керування тими самими RGB-контролерами. Прошивки / драйвери ядра програма не встановлює. OpenRGB та системний NVIDIA-драйвер у цей архів не входять.

Автозапуск додає задачу поточного користувача (logon +10 с). Є подієве відновлення після збою без окремого сервісу. Вимкни автозапуск перед перенесенням / видаленням папки або зареєструй його з нового шляху. `VeryLightRGB.exe --disable-startup` прибирає задачу; налаштування зберігаються.

Окремий Setup.exe встановлює програму для поточного користувача, пропонує автозапуск/ярлик і додає видалення через Windows Installed apps. Оновлення зберігає налаштування, видалення залишає їх у `%LOCALAPPDATA%\VeryLightRGB`.

У комплекті `with-OpenRGB` також є офіційні архіви OpenRGB 1.1 та його вихідного коду в `third_party/openrgb/dist`, ліцензія й скрипти `scripts/setup-openrgb.ps1`, `start-openrgb.ps1`, `stop-openrgb.ps1`. Інструкція та результати: `third_party/openrgb/README.md`, `docs/openrgb-integration.md`. OpenRGB не запускається автоматично.

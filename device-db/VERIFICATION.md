# Перевірки бази й serverless provider

Перевірено 2026-11-01 у цьому workspace.

* Імпорт: 3042 записи, 2477 різних назв, 631 family, 301 LED-layout. SHA-256 кожного з 2136 вхідних файлів звірено з manifest.
* Виконуване повне ядро: 1083 C/C++ translation units; 2144 реєстрації / 1928 назв. 2130 записів основної бази зіставлено за назвою, транспортом і повними витягнутими ідентифікаторами.
* 12 Node test cases пройшли: статичний парсер/імпорт, реальні ID, PID-array/table expansion, pinned hashes, API, відмова для невідомих детекторів, відсутність TCP connections та Qt imports.
* 40 native packet/matching/provider checks пройшли без відкриття обладнання.
* Повний API перевірено 10 послідовними прогонами по 12 assertions на контролері в пам'яті. Знайдену гонку початкової ініціалізації frame flags виправлено в окремому cached core, не у головній програмі.
* Пакет перевірено за SHA-256 усіх включених файлів; розпаковані light EXE та повне ядро успішно виконали offline summary / memory self-test.

На цьому ПК виконано тільки read-only HID inventory (27 endpoint). Новий core не виконував реального апаратного open/scan/frame. Роботу сторонніх фізичних моделей, sleep/resume, гаряче перепідключення й інтеграцію з поточним tray/engine не заявлено перевіреними. Усі нові providers лишаються experimental, `hardwareVerified:false`.

Початкова фаза вище стосувалася окремих інструментів. Після додаткової вказівки користувача provider інтегровано, зібрано й встановлено в Very Light RGB 1.1.0. Перевірено 1370 software assertions / 1404 assertions із native hardware suite та реальний Razer із трьома зонами: 22 секунди статичного режиму, off/on, контрольований збій worker і відновлення. Повний початковий вибір зон і стилів повернуто. Актуальні подробиці — у `docs/native-driver-integration-v1.1.md` основного репозиторію. Системні драйвери й firmware не змінювалися.

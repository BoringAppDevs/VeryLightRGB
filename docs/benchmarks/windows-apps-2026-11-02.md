# Ресурси RGB-програм у Windows: 2 листопада 2026

Локальні вимірювання для майбутніх промоматеріалів Very Light RGB. Програми запускалися по черзі на одному ПК, після завершення першого налаштування, зі згорнутим вікном. Кожен наведений результат — один інтервал приблизно 60 секунд.

Це вимірювання витрат ресурсів у зазначених сценаріях. Ефекти, кількість виходів і підтримка пристроїв відрізняються. Час запуску, затримку керування та швидкість анімацій цей тест не вимірює.

## Результати

| Програма | Відомий обсяг файлів, MiB | Приватна фізична RAM, MiB | Сума working set, MiB | CPU усього ПК |
| --- | ---: | ---: | ---: | ---: |
| **Very Light RGB 1.2.0** | **79,15** | **3,77** | **17,69** | **0,099%** |
| OpenRGB 1.1 | 48,88 | 34,41 | 98,82 | 0,028% |
| SignalRGB 2.5.84 | 1123,56 | 647,76 | 1004,06 | 1,092% |
| MSI Center 2.0.75 + Mystic Light 3.0.37.2 | 1832,63 | 166,60 | 437,03 | 0,167% |
| Razer Chroma на наявній інсталяції Razer/Synapse | ≥2725,62 | 1000,24 | 2328,94 | 0,113% |

MiB = 1 048 576 байтів. RAM — середнє значення вибірок. Приватна фізична RAM не включає спільні сторінки; підсумовування повних working set різних процесів може повторно враховувати їх. Private commit також збережений у даних, але це окремий показник віртуальної пам'яті.

Обсяг файлів включає перелічені в JSON каталоги програм, даних і кешів. Це відомий обсяг на цьому ПК, а не приріст після чистого встановлення. Загальні кеші Windows Installer і Driver Store враховані не повністю. Для Razer один підкаталог ProgramData був недоступний під час підрахунку, тому результат є нижньою межею.

У повний комплект Very Light RGB включено вихідний код SOURCE.zip розміром 35,47 MiB, драйвери, ліцензії та деінсталятор. Основний EXE займає 1,97 MiB. **Повний комплект OpenRGB у цьому вимірюванні менший за наш.**

## Обладнання і сценарії

- Windows 11 Pro 10.0.26300; AMD Ryzen 7 9800X3D; 16 логічних процесорів; 32 GiB встановленої RAM.
- MSI MAG B850M MORTAR WIFI; Gainward GeForce RTX 5080 Phoenix; підключена периферія, зокрема Razer Basilisk V3 Pro.
- **Very Light RGB:** Native Auto, меню закрите, Rainbow на трьох ARGB-виходах із довжинами 13/12/12 LED та GPU. Чотири виходи повідомили успішний стан. Додатковий процес ядра драйверів не запускався. Використано копію поточних налаштувань в окремому каталозі.
- **OpenRGB:** звичайний GUI, три виявлені контролери — GPU, миша і MSI Mystic Light; вікно згорнуте. Без Effects Plugin і програмної анімації. Автоматично встановлену службу OpenRGB зупинено перед запуском GUI, щоб не запускати два контролери одночасно. Тому нижчий CPU OpenRGB тут не є порівнянням однакових анімацій.
- **SignalRGB:** гостьовий режим, стандартний ефект Neon Shift, вікно згорнуте; материнську плату виявлено. Керування вентиляторами відхилено. Включені launcher, основний процес, його WebEngine-процеси та служба. Версія служби 0.2.16, потрібний драйвер SignalIO 1.3.9 встановлено до тесту.
- **MSI:** Center 2.0.75.0, SDK 3.2026.1013.01, єдиний додатково вибраний модуль Mystic Light 3.0.37.2. Материнську плату виявлено, Mystic Light увімкнено. Включені служби й дочірні процеси, зокрема LEDKeeper, LightKeeper і CC_Engine. Додані модулем ENE HAL включені в обсяг файлів.
- **Razer:** AppEngine/запис інсталяції 4.0.896, Chroma 4.0.63.2610281118, стандартні Quick Effects. Synapse 4.0.827 та частина спільних файлів були на ПК до тесту. RAM включає запущені спільні служби Razer; диск включає наявні компоненти Synapse, Razer Experience, кеш інсталятора та дані користувача. **Цей рядок не показує ізольоване чисте встановлення лише Chroma.**

## Метод і дані

[measure-app-suite.ps1](../../scripts/measure-app-suite.ps1) збирає лічильники Win32_PerfRawData_PerfProc_Process приблизно раз на секунду. Враховуються процеси програми, її служб і дочірні процеси. Нові версії скрипту також перевіряють час створення батька, щоб уникнути помилкового приписування через повторне використання PID.

CPU обчислено як приріст процесорного часу / фактичний час вибірки / 16 × 100%. У підсумкових даних усі інтервали нормалізовані за Stopwatch; початкові вимірювання OpenRGB і Razer додатково звірені з часовими мітками лічильників. RAM і CPU драйверів ядра та робота поза приписаними процесами до цих показників не входять. Процес, який повністю запустився й завершився між вибірками, може не потрапити в облік.

[JSON із результатами та знеособленими вибірками](windows-apps-2026-11-02.json) містить тривалість кожного запуску, RAM, CPU, деталізацію каталогів і перевірку очищення. PID, ім'я користувача, особисті шляхи, серійні номери й конфігурації пристроїв до публічного JSON не включені. Первинні діагностичні файли залишені в ігнорованому Git каталозі local/competitor-benchmark-20261102.

Для файлів записані логічні розміри та, де доступно, FileStandardInfo.AllocationSize. Метадані NTFS, резидентні файли та спільні hard link можуть впливати на фактично зайняте чи звільнене місце. Однаковий фіксований час прогріву і повторні серії не проводилися; результат не слід подавати як універсальний рейтинг.

## Очищення і використання в промо

Після тесту видалені OpenRGB, SignalRGB, MSI Center/Mystic Light та Razer Chroma/Synapse, їхні допоміжні компоненти й тимчасові інсталятори. Службу та драйвер SignalRGB видалено; драйвер NTIOLib_MysticLight штатно зупинено й видалено. ENE-модулі та MSI Appx-пакет також видалені. Залишки каталогів і кешів прибрані.

Підсумкова перевірка: **0 процесів, 0 служб, 0 тестових драйверів, 0 записів встановлення, 0 Appx-пакетів, 0 записів Run і 0 запланованих завдань для протестованих конкурентів.** Початкові налаштування Very Light RGB не змінені; фонову роботу та чотири успішні виходи підсвічування відновлено. Попередньо встановлений спільний PawnIO збережений.

Коректне формулювання для промо: «У нашому 60-секундному тесті на Windows 11 Very Light RGB 1.2 використовував у середньому 17,7 MiB working set і 0,099% CPU, керуючи Rainbow на трьох ARGB-виходах та GPU, із закритим меню». До порівняльної таблиці потрібно додавати посилання на сценарії та метод. Дані не доводять тверджень «найшвидша», «найменша на диску» або однакової переваги на будь-якому ПК.

Version 1.1 adds a separate, GPL-licensed native driver-core worker using local
stdio pipes. It does not start an OpenRGB SDK server and is not linked into
the main tray EXE. Original source archives, build bridge and dependency
notices are shipped in native-drivers/sources and native-drivers/licenses.
All transport DLLs are built from pinned source; no separate MSVC runtime is required.

Native RGB transports were implemented from the project's previously
verified MSI HID and Gainward NVAPI protocols. OpenRGB SDK interoperability
uses an independently implemented loopback TCP client, protocol version 3.
The stock OpenRGB GUI/SDK application is not linked into this EXE.
Version 1.1 includes a separate server-free driver core derived from OpenRGB;
its source archives and notices are shipped in native-drivers/.
An optional separate with-OpenRGB distribution includes the unmodified
OpenRGB 1.1 portable and source archives. Its GPL license, Qt license texts,
version manifest and notices are in third_party/openrgb/.
Protocol documentation:
https://gitlab.com/CalcProgrammer1/OpenRGB/-/blob/master/Documentation/OpenRGBSDK.md

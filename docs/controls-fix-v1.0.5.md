# Виправлення кольорів і режимів — 1.0.5

2026-11-01. Симптом: у «Усе разом» колір / ефект зберігалися в меню, але світло не змінювалося; power працював.

Причину підтверджено живою конфігурацією: обидва керовані виходи мали `UseGlobal=false`. Меню редагувало тільки глобальний шаблон, тоді як renderer правильно використовував їхні незалежні стилі. Master power завжди застосовувався до незалежних зон, тому залишався робочим. Додатково меню показувало глобальний ефект 4, хоча фактичні ефекти виходів були 1 та 0; через це приховувало корисні параметри.

## Виправлення

- Додана явна операція агента `edit-lighting`: у scope «Усе разом» змінює **тільки вибране поле** в усіх керованих виходах поточного backend, включно з незалежними. Незачеплені поля, link-прапорці, порожні / невибрані хедери зберігаються.
- У scope одного виходу редагується тільки цей вихід. Для linked-зони копіюється поточний ефективний стиль і автоматично вимикається link; редагування не блокується мовчки.
- Master power лишається окремим від локальних power-прапорців. Зміна кольору linked-зони під час master-off не залишає її назавжди вимкненою після master-on.
- Меню бере параметри з фактичних стилів. При розбіжностях показує «Різні ефекти», «Різні кольори», «Різна яскравість». При змішаних ефектах не приховує керування кольором через невикористаний глобальний шаблон веселки.
- Revision перевіряється під час запису; застарілі запити відхиляються. `set-config` не змінив семантики й використовується для точного відновлення / міграції.

## Перевірки

**1308 assertions** базового набору пройдено. Нові регресійні сценарії: broadcast кольору / ефекту / яскравості незалежним стилям, збереження інших полів та невибраного хедера, автоматичний detach linked-зони, master-off/on, відмова невибраному scope / невідомому полю / stale revision. TCP-емулятор перевірив реальні нові color bytes для двох зон та анімаційні кадри після зміни ефекту. 432 еталонні кадри renderer залишилися ідентичними.

Після встановлення перевірено **той самий RPC, який викликає меню**, на реальних MSI ARGB 1 та Gainward RTX 5080 Phoenix:

| Команда | Незалежне фізичне читання |
|---|---|
| Усім 15%, статичний червоний | MSI RGB 38/0/0; GPU регістри 6C/6D/6E = 38/0/0 |
| Усім синій | MSI RGB 0/0/38; GPU 0/0/38 |
| Тільки GPU #64E6C6 | GPU 15/34/29; MSI лишився синім 0/0/38 |
| Усім ефект «Дихання» | Обидва статуси успішні, правильна назва ефекту, 18 надісланих анімаційних кадрів за ~1 с |

Тести тимчасово змінювали світло. Після них повна конфігурація повернута до snapshot перед перевіркою; рівність підтверджена. Renderer та пакети апаратних модулів не змінювалися.
